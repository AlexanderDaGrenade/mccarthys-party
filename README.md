# McCarthy's Party — website redesign concept

A modern redesign concept for [McCarthy's Party](https://www.mccarthysparty.com), escorted tours of Newfoundland & Labrador since 1982.

Static site (HTML/CSS/JS, no build step). Tour content and photography come from the current mccarthysparty.com site.

- `index.html`: page structure
- `data.js`: tours, day tours, seasons, reviews and guides (edit content here)
- `app.js`: interactions (trip finder, tour drawer, seasonal guide, reviews carousel, enquiry form)
- `styles.css`: design system and responsive layout

Run locally: `python3 -m http.server` and open http://localhost:8000
